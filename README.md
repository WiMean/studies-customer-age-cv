# Определение возраста покупателей по фотографии (CV)

**Задача.** Сетевой супермаркет внедряет компьютерное зрение в прикассовой зоне, чтобы определять возраст клиентов. Нужна модель, которая по фотографии определяет приблизительный возраст. MAE не выше 8.

**Что сделано.** Исследовательский анализ набора из ~7,6 тыс. фотографий, аугментации, обучение и дообучение ResNet50 (TensorFlow/Keras), контроль переобучения, оценка на тестовой выборке.

**Стек.** Python, TensorFlow/Keras, ResNet50, pandas, NumPy, Matplotlib

**Результат.** MAE 6,4 года при пороге 8

**Ноутбуки:**

- `customer-age-cv.ipynb`
